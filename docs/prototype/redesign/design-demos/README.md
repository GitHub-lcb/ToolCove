同一屏内容（运行停在第 5 步、要覆盖写一个 JSON），三种骨架。都是单文件、离线可开、可点击。

| 文件 | 方向 | 骨架 | 一眼看什么 |
|---|---|---|---|
| [dir-1.html](dir-1.html) | A · Console（参照 Linear） | 顶栏 + 图标轨 + 单列块流 + 右栏 | 光标停在闸门；diff 摊在流里，不弹窗 |
| [dir-2.html](dir-2.html) | B · Pipeline（Bret Victor） | 横排 8 节点链 + 检查器 + 零件箱 | 断点画成虚线：允许后电流才接通 |
| [dir-3.html](dir-3.html) | C · Desk（参照 Zed） | 三栏编辑器：工具 / 文档 diff / Agent | 批准是文档底部的签字，Diff 是主角 |

截图：[`shots/`](shots)（1440×900）。六格缩略图（含三个备选）：[`thumbs.html`](thumbs.html)、[`thumbs.png`](thumbs.png)。

## 三版都能点的

- **第 5 步的确认**：允许 → 6-8 步继续、状态变「已完成」；拒绝 → 停住，并写明磁盘/数据库没有改动。
- **单步与文档**：A 点「详情」展开参数与原始结果；B 点任意节点切换检查器；C 切「改动 / 结果预览」。
- **命令面板**：A、B 里按 `Ctrl/⌘ + K`。
- **导航 / tab**：A 的「执行 / 产出」，B 的「过程 / 产出」，C 的「改动 / 结果预览」、左侧工具选中态。
- 控制台零报错；三版都在 1120×760 下验过可用。

## 与规范的偏差（诚实说明）

- 正文字号 12.5–13.5px，而不是网页的 14px：这是桌面应用的密度（与仓库 `tokens.css` 的 `--fs-md: 13.5` / `--fs-sm: 12.5` 对齐），三版一致。
- 品牌标记按各方向的介质做了单色 / 原色处理（见 `brand-spec.md`），形状未改。
- `design_lint.py` 的自动体检在本机跑不起来（Python Playwright 的浏览器版本缺失），改用 Node Playwright 截图 + 手查对比度/字号/交互；这一步在交付说明里注明了。
