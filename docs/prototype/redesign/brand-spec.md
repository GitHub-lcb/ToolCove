## 颜色

- 品牌蓝：`#0969DA`（浅色强调）/ `#4493F8`（深色强调），来自 logo 渐变与默认强调色预设。
- 语义色（跨页面统一）：运行中蓝 / 等待橙 / 完成绿 / 失败红（tokens.css 的 `--run-* / --wait-* / --done-* / --fail-*`）。
- 中性色：浅色 `--bg` 系与深色 `--bg` 系各自成套，不跨主题借色。

## 字体

- 界面：Segoe UI / 苹方 / 雅黑（`--font-sans`）。
- 数据与代码：Cascadia Code / Consolas（`--font-mono`）。
- 数字与版本：Bahnschrift（`--font-num`）。

## 使用规则

1. 标记形状不改（圆角方块 + 笑脸），本轮允许**单色化**以适配深色或单色版面；正式落地仍用原渐变资产。
2. 品牌蓝在每屏只承担「当前/可点/已确认」这三类含义；等待确认用等待橙，不与品牌蓝混用。
3. 不新造第二套品牌色；三个方向里的其他颜色只能是中性色或语义色。

## 本轮的处理

三个方向都保留标记的形状；Console 用单色白、Desk 用原渐变、Pipeline 用单色墨。这是「同一资产、三种介质」，不是三个新 logo。
