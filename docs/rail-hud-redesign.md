# 铁路大亨 · 驾驶舱改版设计（C 方案）

日期：2026-09-17（2026-09-18 更新窗口尺寸与自动填入）
状态：已实现
范围：桌面端「铁路大亨站点推断」工具（驾驶舱为主，完整版面/手机版同步色彩与编号）

## 1. 背景与目标

现状问题（来自实机截图与走查）：

- 编号口径与用户口径不一致：用户要求**始发站 = 第 1 站**，之后依次 2…16（现实现始发站不编号，第 N 站落在下标 N 上）。
- 驾驶舱三条信息带（顶栏细条 / 记录卡 + 推断卡 / 大段建议文字）主次不清；16 格记录条被挤在顶栏只有 ~15px 宽，看不出是核心信息。
- 「这一站怎么做」最多 4 条三级文字，跑商时读不完；真正需要警觉的（如连站时不能拿「下一站售价提升」）被埋在正文里。
- 类型颜色（酒/食/商）与状态颜色混用，界面花；颜色被用来单独表意。

目标：**路线条成为核心展示区**；结论长在路线上；建议压缩为「一句提醒 + 一句动作」；全工具只保留一种彩色（100% 锁定），状态用形状/文字共同表达。

## 2. 编号口径（全局）

- `stationNumber(index) = index + 1`：始发站 = 第 1 站，终点站 = 第 16 站。
- 影响面：站名、当前站/下一站标题、提示覆盖范围、冲突诊断文案、完整版面首列、手机版站名与覆盖范围，全部随 `stationNumber()` 一处改动生效。
- 始发站格显示编号 1 + 「始」（无类型）；其余格显示编号 + 类型字。
- `hintRange` 仍返回下标区间，视图层经 `stationNumber` 换算，因此覆盖文案自动变为「→ 第 15~16 站」这类新口径。

## 3. 驾驶舱版面（C 方案）

窗口尺寸改为**矮而宽**（默认 760×340，min 560×250；行高 max-content、超出由工具自己滚）：
路线行水平铺开，卡片贴合内容，不在卡片内部留大块空白。

自上而下四段：

1. **工具栏（28px）**：左「铁路大亨 · 挑战线路」+ 可点击的「漏 N 条提示」；右为图标按钮：全部记录、完整版面、复制结论、清空重来（悬浮按钮在有容器能力时显示）。图标按钮带 `title` + `aria-label`。
2. **路线行（76px，核心）**：16 格 flex，底对齐。
   - 普通格 52px 高：左上角站号（11px、tabular-nums、#64748B），居中类型字（17px）。
   - 已录入：灰底（#F1F5F9）+ 中性字色（#334155），对比度 9.45:1。
   - 未知：虚线边框 + 居中浅灰「?」（#64748B，4.76:1）。
   - **气泡（当前记录站 = 光标所在站）**：与下方录入卡说的是同一站——避免「上面放大第 5 站、下面在记第 4 站」的割裂。
     未录入且锁定时：类型名 + 100% 已确定（主色，全窗口唯一彩色）；未录入且待定时：头名候选 + 占比条；
     已录入（含推断自动填入）时：类型名 + 还差什么（如「还差本站提示」）。
     「下一站是什么」由路线上的虚线锁定格（推断已确认）与右侧动作 chip（含类型名）承担。
   - 游标：贴在气泡上沿的小三角（当前记录站与气泡通常同格；回改历史站时两者分开）。
   - 欠提示：格角空心小圈（去色），`title` 说明第几站欠提示。
3. **记录卡 + 提醒列（两栏）**：
   - 记录卡：标题「记录 · 第 N 站」；类型行 3 个按钮；提示行 4 个按钮；**覆盖范围独立成行**（虚线分隔、固定行高，不因窗口宽度换行）。
   - 提醒列：连站等坑才显示琥珀警告条（主句「别做什么」+ 次句「为什么」，两行同左基线）；下方一条动作 chip（拿什么卡）。
     **卡片底部是下一步操作**：本站记全后出现主按钮「去第 N 站」（手动推进）；没记全时用一句浅色说明
     「记全本站后，从这里去下一站」填住空白——这块曾是大片空白。
4. **全部记录覆盖层 / 清空确认层 / 完整版面**：结构保留，仅同步编号与去类型色。

## 4. 颜色与状态（全工具统一）

- **唯一彩色 = 100% 锁定**（primary 蓝）：用于气泡、完整版面「已锁死」标签、锁定占比条。
- **警告**：琥珀色（`--warn*`），只用于提醒条；**冲突**：危险红，只用于矛盾状态。
- 类型不再着色：类型标签、按钮、路线条、推断胶囊、占比条全部中性（灰阶）。
- 颜色不做唯一表意：已录入/未知/锁定/欠提示同时有形状或文字差异（实底/虚线/描边+小圈/文字），满足 color-not-only。
- 选中态（类型/提示按钮）：蓝描边 + 内侧左竖条 + 文字变蓝（形状差异），未选中中性白底。

## 5. 交互与动效

- **推断已确定的站自动填入类型**：光标落到推断唯一确定（100% 锁定）的站时，类型自动记上，
  玩家只需再选提示；自动填入的格子用虚线下划线标出（与亲眼录入区分），手动改过后标记消失。
  该操作不改变解空间（所有合法排列本就都取这一类），只是把已知结论落到记录上。
- **不自动前进**：记完当前站（类型 + 提示）后光标留在原站——玩家还在本站购物、选卡，
  自动跳站会让「当前站」跟着跑到下一站。推进由右侧底部的「去第 N 站」按钮手动触发（`goNext`）；
  推进时下一站若推断已确定，类型自动补上；已记全的站会被跳过。
- 气泡跟随光标：推进后气泡以 transform/opacity 过渡到下一格（160ms，ease-out）；`prefers-reduced-motion` 下直接切换，不做过渡。
- 气泡内容切换（锁定 ↔ 待定）用淡入，不改变自身尺寸布局（避免 CLS）。
- 路线格不可点击（改历史仍走「全部记录」），但每格带 `title`（站号 · 状态 · 类型）。
- 欠提示「漏 N 条」入口点击切到完整版面补录（保留现行为）。

## 6. 响应式

- ≥620px：单行 16 格（默认 640 窗口）。
- <620px：路线行折成两行 8 格，气泡落在第二行；记录卡与提醒列改为纵向堆叠；由 `.rail-tool` 整体滚动。
- 最小窗口 560×320 下不出现横向滚动。

## 7. 无障碍

- 文本对比度 ≥4.5:1：站号 #64748B、正文 #334155、次说明 #6B7280、气泡 #1D4ED8/#EFF6FF、警告 #92400E/#FFFBEB（实测 4.76 / 10.35 / 4.83 / 6.16 / 6.84）。
- 图标按钮均有 `aria-label`；`qbtn` 保持 `aria-pressed`；警告条 `role="status"`。
- 焦点样式沿用全局 `:focus-visible` 规范，不被移除。

## 8. 测试与验证

- `railTycoon.test.js`：`stationNumber` 全量改 +1；其余规则测试不受影响。
- `RailTycoonTool.render.test.js`：更新站号断言（1..16）；新增路线行/提醒条结构断言。
- `mobile/rail-hud/*.test.js`：站名、覆盖范围、记录条文案同步。
- i18n（中英）：新增/修改连站提醒短句、覆盖范围单站变体（已有）、未知格 aria 文案；手机端 `i18n.gen.js` 与 `dist`、Android assets 重新生成。
- 人工验收：640×410 与 560×320 两个尺寸；连站提醒出现/消失；待定气泡占比条。

## 8b. 手机端同步（桌面端行为的对齐）

- 手动推进：手机端也没有自动跳站，录入区底部出现「去第 N 站 →」；没记全时显示
  「记全本站后，从这里去下一站」。
- 推断自动填入：到站（推进或手动选站）时，推断已确定的站自动补类型，网格里用虚线下划线
  标记来源；手动改过后标记消失。判定抽到 `view.js` 的 `lockedTypeAt`，有单测。
- 横竖屏切换：录入区头部一个「横屏 / 竖屏」小按钮（显示的是目标方向），经
  `railHudApi.setOrientation()` 调原生：
  - 悬浮面板 = 换窗口尺寸（竖屏 360×272dp，横屏 560×200dp）+ `data-orient` 切到左右分栏；
  - 全屏页 = 改 `requestedOrientation`（手机锁了自动旋转时也能主动转），选择持久化，
    下次开窗口由 bootstrap 注入。
- 打包：`railpanel-v*` 标签触发，与桌面端发版线完全独立；工作流带 `make_latest: false`，
  安卓版 Release 不会顶掉桌面端更新器读的 `/releases/latest/latest.json`。

## 9. 不做的事（YAGNI）

- 不改求解器与导入导出协议（除编号文案）。
- 不给路线格加点击跳转（保留「全部记录」单一回改入口）。
- 不引入新依赖、不做主题系统重构。

## 10. 已确认的设计决策

- 布局方向：C「推断长在路线上」（用户在对比页选定）。
- 颜色：只区分 100% 锁定与其他；只保留一种彩色 + 警告/冲突语义色（用户提出）。
- 单色化范围：**全工具统一**（驾驶舱 + 完整版面 + 手机版）。
- 欠提示标记：**空心小圈**（去色）。
- 站号：始发站 = 1，之后 2…16（用户两次强调）。
- 尾段「各站点数量相同」的口径修正（游戏实测）：2 站窗口 = 两站类型不同（1+1+0），
  不是三类计数相等；1 站窗口永远不成立。原先把 2 站窗口判成无解，导致误报「记录有矛盾」。
- 光标不自动前进：记完提示后留在本站（玩家还在购物/选卡），由右侧底部「去第 N 站」手动推进。
